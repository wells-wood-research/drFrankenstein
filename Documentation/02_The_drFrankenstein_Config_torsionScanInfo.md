# `torsionScanInfo`

This section gives `drFrankenstein` information about the torsion scanning protocol you want to run.

### `runScansOn`
This option is a series of booleans that allows you to skip scanning/fitting certain classes of torsion angles. If a torsion is skipped, the by-analogy parameters generated by parmchk2 will be used instead. It can be expensive to parameterise all torsion angles for large systems, so terminal polar and non-polar protons can be skipped.

You may want to use canonical torsion angle parameters to describe an ncAA's Phi and Psi angles. If so, set `PhiPsi` to `false`; `drFrankenstein` will automatically assign AMBER19SB's Phi and Psi parameters.
- Type: `dictionary`
- Required: yes
- Validation: each value in this dictionary must be `boolean`
- Defaults helper seeds these keys:
  - `phiPsi` (default `true`)
  - `polarProtons` (default `true`)
  - `nonPolarProtons` (default `false`)

### `nConformers`
This sets the number of conformers to perform torsion scans on. More conformers produce smoother final QM scan energies but increase calculation time.
- Type: `integer`
- Required: yes
- Constraint: must be `>= -1` (`-1` means use all available)
- Default : `-1`

### `scanMethod`
This is the QM method used to perform relaxed torsion scans. It must be a valid main input for ORCA. Do not include the leading `!` character or solvation keywords.
- Type: `string`
- Required: yes
- Default: none

### `scanSolvationMethod`
This is the solvation method used for relaxed torsion scans. It must be compatible with `scanMethod`. Set to `null` for gas-phase scans (not recommended).
- Type: `string` or `null`
- Required: no
- Default : `null`

### `singlePointMethod`
This is the QM method used for optional single-point recalculation of scan windows. It must be a valid main input for ORCA. Do not include the leading `!` character. Set to `null` to skip recalculation.
- Type: `string` or `null`
- Required: no
- Default : `null`

### `singlePointSolvationMethod`
This is the solvation method used for optional single-point recalculation of scan windows. It must be compatible with `singlePointMethod`. Set to `null` to skip single-point recalculation in the gas phase (not recommended).
- Type: `string` or `null`
- Required: no
- Default : `null`

### `nCoresPerCalculation`
The number of CPUs to use per scan and single-point calculation. If `nConformers` is less than your total available CPUs, increase this value; otherwise `1` should be fastest.
- Type: `integer`
- Required: no
- Constraint: must be positive and cannot exceed `miscInfo.availableCpus`
- Default : `1`
